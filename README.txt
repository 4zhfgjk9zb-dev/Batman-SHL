BATMAN SHL – kostenlose statische Website

Dateien:
- index.html
- styles.css
- script.js
- assets/logo.jpg (unverändertes, vom Kunden geliefertes Logo)

Kostenlos online stellen:
1. GitHub Pages: Repository erstellen, Dateien hochladen, Settings > Pages aktivieren.
2. Cloudflare Pages: Ordner/Repository verbinden und als statische Website veröffentlichen.
3. Netlify: Den kompletten Ordner per Drag & Drop deployen.

Die Website benötigt kein WordPress, keinen Baukasten und keine kostenpflichtige Software.
Die verwendeten Hintergrundfotos werden extern über Unsplash geladen. Sie können später durch eigene Referenzfotos ersetzt werden.

Hinweis:
Impressum und Datenschutz sind aktuell nur Platzhalter-Links und müssen vor Veröffentlichung ergänzt werden.
